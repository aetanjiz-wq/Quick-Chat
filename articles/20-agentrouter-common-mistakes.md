# Common AgentRouter Setup Mistakes to Avoid

AgentRouter is fairly straightforward once the client is pointed at the right compatibility endpoint, but a few mistakes appear again and again.

The first is using an OpenAI-compatible URL for an Anthropic-style client, or the reverse. The second is copying an old model ID from a tutorial instead of checking the current dashboard. The third is storing API keys directly in a repository or screenshot.

Another mistake is testing immediately on a large private project. Start with a small sample so you can confirm authentication, model access, usage tracking, and client behavior first.
