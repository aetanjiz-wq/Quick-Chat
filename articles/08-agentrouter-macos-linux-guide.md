# AgentRouter on macOS and Linux

On macOS and Linux, AgentRouter can be used with supported coding tools by exporting the API key and the base URL expected by the client. The exact variable names depend on whether the tool is using an OpenAI-compatible or Anthropic-compatible connection.

A good setup keeps secrets out of the repository. Put them in your shell environment or a secure local configuration and avoid committing them to GitHub.

When testing, start with a lightweight prompt and confirm that authentication, the selected model, and the endpoint all work before running a large coding job. If a tutorial uses an old model name, check your current AgentRouter dashboard rather than assuming it still exists.
