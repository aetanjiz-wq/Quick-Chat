# Privacy Checklist Before Using AgentRouter with Private Code

An AI router can be convenient, but convenience should not replace a privacy review. If you plan to send business code, credentials, customer data, or internal documents through a third-party service, check how that data is handled first.

Review the current privacy policy, terms, retention rules, subprocessors, logging practices, and whether prompts or outputs may be stored. Also confirm which upstream model providers may receive the request.

Do not paste production secrets into prompts. Keep API keys in secure local configuration and use test repositories until you understand the data path.
