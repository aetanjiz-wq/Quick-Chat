# AgentRouter Setup Checklist

Before connecting an AI coding tool to AgentRouter, run through this short checklist.

1. Create your AgentRouter account.
2. Generate or copy your API key securely.
3. Identify whether your client expects an OpenAI-compatible or Anthropic-compatible endpoint.
4. Check the current model IDs available in your account.
5. Store the API key in an environment variable or secure local setting.
6. Test with a small, non-sensitive project.
7. Confirm usage, balance, and rate limits after the first few requests.
8. Review privacy and data-handling terms before using confidential code.

Most setup failures come from the wrong endpoint style, a stale model name, or an environment variable that the client cannot see.
