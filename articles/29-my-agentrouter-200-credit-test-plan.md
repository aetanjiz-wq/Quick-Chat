# How I Would Use $200 of AgentRouter Credits for Testing

If you receive a meaningful amount of AI API credit, it is easy to burn through it without learning much. A better approach is to create a small test plan.

I would divide the budget across a few tasks: code explanation, bug fixing, refactoring, documentation, and one larger repository task. I would then run similar prompts in different compatible clients and compare quality, speed, context handling, and cost.

That makes the credit useful as an evaluation budget rather than just free usage. Keep notes on which model and client combination works best for each type of task.
