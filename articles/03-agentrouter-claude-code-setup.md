# Using AgentRouter with Claude Code

Claude Code is one of the most useful terminal-based coding assistants for repository work. AgentRouter can be connected through an Anthropic-compatible endpoint, which makes it possible to route supported Claude-style traffic through a single AgentRouter account.

The main configuration point is the Anthropic-compatible base URL. For this type of integration, use the AgentRouter endpoint without adding `/v1`. Then provide your AgentRouter API key through the environment variable expected by the client and select a model that is currently available in your dashboard.

A good first test is a small repository task such as asking Claude Code to summarize a project, find a bug, or explain a function. Avoid starting with sensitive production code until you have reviewed the router's current privacy and data-handling policies.
