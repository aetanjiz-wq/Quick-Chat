# Using AgentRouter with OpenCode

OpenCode is useful if you prefer a terminal coding agent with flexible provider support. AgentRouter can fit into that workflow through an OpenAI-compatible provider configuration.

The cleanest setup is to create a custom provider, point it to AgentRouter's OpenAI-compatible base URL, and select a model ID that is actually available in your account. Keep your API key outside the project files whenever possible.

Once connected, start with a small task: ask OpenCode to explain a repository, search for a bug, or propose a safe refactor. If authentication works but the model fails, verify the model name and account balance before changing the rest of your configuration.
