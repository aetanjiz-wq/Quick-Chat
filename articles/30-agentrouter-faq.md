# AgentRouter FAQ for Developers

## What is AgentRouter?

It is an AI routing service that can expose compatible API endpoints for use with supported coding tools and clients.

## Why use a router instead of one direct provider?

The main reason is flexibility: one routing account can make it easier to work with multiple compatible tools or model families.

## Which coding tools can I try?

Examples include Claude Code, Codex, OpenCode, Cursor and several VS Code agent extensions, depending on current compatibility.

## What causes most setup errors?

Common causes are the wrong compatibility endpoint, an invalid API key, an unavailable model ID, or an environment variable that the client cannot read.

## Should I use it with confidential code?

Review the current privacy, retention and data-handling terms first. Treat any third-party router as infrastructure between your client and the model provider.
