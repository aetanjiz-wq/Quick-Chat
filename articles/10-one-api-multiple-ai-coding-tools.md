# One API for Multiple AI Coding Tools: Why Routers Are Useful

Developers increasingly use more than one AI coding client. One day it may be Claude Code, another day Codex, OpenCode, Cursor, Cline, or a different editor extension. The advantage is not that every tool becomes identical. Each client still has its own features and configuration. The value is that model access and account management can be more centralized.
