# Using AgentRouter with Cline, Roo Code and Kilo Code

VS Code agent extensions such as Cline, Roo Code and Kilo Code can often connect to compatible custom providers. AgentRouter can be useful when you want one routing account behind several editor agents.

The main decision is whether the selected model and client should use an Anthropic-compatible or OpenAI-compatible connection. Configure the matching endpoint, keep your API key private, and choose a model ID available in your AgentRouter dashboard.

Test each extension separately because provider settings and supported features can differ between clients. A setup that works in one extension should not automatically be assumed to behave identically in another.
