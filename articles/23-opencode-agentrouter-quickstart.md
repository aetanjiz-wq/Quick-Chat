# OpenCode + AgentRouter Quick Start

OpenCode is a good fit for developers who like terminal-based agents and flexible provider configuration. AgentRouter can be added as an OpenAI-compatible custom provider, letting you keep OpenCode while experimenting with models available through the router.

Keep the API key outside the repository, point the provider at the correct base URL, and use a model name from your current AgentRouter dashboard. Then test with a small coding request before attempting a long autonomous session.

If the provider authenticates but the model fails, model availability is the first thing to check. If the client cannot connect at all, verify the endpoint and environment variables.
