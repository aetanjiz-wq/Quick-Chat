# A Practical AgentRouter + VS Code Workflow

VS Code users often combine several AI extensions and terminal tools in the same project. AgentRouter can simplify that setup by giving compatible clients a common routing account instead of requiring a completely separate provider workflow for each tool.

One useful approach is to keep VS Code for editing, run Claude Code or Codex in the integrated terminal, and use a compatible extension such as Cline or Roo Code when you want an agent inside the editor. The important part is to configure each client with the endpoint format it expects.

Do not hardcode API keys in settings files that might be committed. Use environment variables or secure local settings, then test on a small repository first.
