# AgentRouter Cost-Control Tips for AI Coding

AI coding sessions can become expensive when agents read large repositories, retry repeatedly, or use long contexts. A routing service does not remove that problem, so cost control still matters.

Start with small tasks, limit unnecessary context, avoid asking an agent to scan an entire repository when one folder is enough, and monitor usage after testing a new model. If the client supports it, use cheaper models for routine tasks and reserve stronger models for harder debugging or architecture work.

Credits are best treated as a testing budget rather than unlimited usage. I personally received $200 in AgentRouter credits, but that amount is not guaranteed for every account and current offers can change.
